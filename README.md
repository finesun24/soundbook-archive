# 사운드북 아카이브 시제품

## 바로 보기
1. ZIP 압축을 **먼저 풀어주세요**.
2. 폴더 안의 `index.html` 파일을 더블클릭해 크롬 또는 엣지로 열어주세요.
3. 작품 표지를 클릭하면 개별 재생 화면이 열립니다.
4. 현재 음원은 미등록 상태이며 '준비 중'으로 보입니다.

## 음원 추가
- 예시: 1번 작품의 완성된 MP3 파일을 `audio/01.mp3`로 저장합니다.
- `books-data.js`에서 ID `01`의 `audioReady: false`를 `audioReady: true`로 수정합니다.
- 페이지를 새로고침하면 오디오 플레이어가 나타납니다.
- 작품 소개는 같은 파일의 `description`을 수정합니다.

## QR 인쇄 전 주의
- 이 버전은 로컬 시제품으로, **아직 인터넷에 공개된 주소가 없습니다**.
- QR은 사이트를 호스팅하여 공개 URL을 확보한 후, 각 작품의 `book.html?id=01` 등의 주소로 발급해야 합니다.
- 추후 QR 주소를 유지하려면 호스팅 주소와 작품 ID를 변경하지 마세요.
- 외부 공개 전 2번 작품의 저작권 상태를 확인해주세요.

디자인 결정은 `DESIGN.md`에서 확인할 수 있습니다.
